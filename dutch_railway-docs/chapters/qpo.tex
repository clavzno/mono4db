\section{Query Processing and Optimization}
\label{sec:qpo}

Query optimization is the process where a query's performance is improved. This is important as the larger a database grows, the more 
time and compute resources are needed in order to execute queries. This can both worsen the user experience due to slow execution times, 
while also incurring significantly higher computational cost. Three of the most relevant query processing techniques applied to this OLAP 
application are correct database design, use of indexing, and query restructuring.

First, database design is a key factor in creating fast queries. For example, since the focus of our queries lies in the efficiency of the 
trains, the fact tables center on the services and stops. Additionally, compared to a snowflake schema design, the galaxy schema used allows for 
significantly less JOINS being utilized, which speeds up the process significantly. While the most optimal dataset in terms of raw speed would 
be one large table, this would be incredibly impractical and bloated. This is a large reason why queries 3 and 4 are already fairly fast without 
further optimization as the database design already caters to their needs.
