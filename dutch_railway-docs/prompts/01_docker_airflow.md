# Understanding Docker and Apache Airflow

**Task.** Help understand documentation of Docker and Apache Airflow.

**Model.** Claude Opus 5.5

## Prompt

> I'm a student building a data warehouse project. I'm comfortable with data modelling (star schemas, fact and dimension tables, ETL concepts) but new to [Apache Airflow / running Airflow in Docker].
>
> Act as a teacher, not a coder: do not write code or config for me. Instead:
>
> 1. Explain what [the tool / the integration] is for and what problem it solves, in a few short paragraphs.
> 2. Map its core ideas to data modelling concepts I already know, and say where each analogy breaks down.
> 3. Point me to the parts of the official documentation I should read first, in order.
> 4. End with 3 questions I should be able to answer once I understand it, so I can check myself.
>
> If something depends on a version or setup detail, ask me instead of assuming.
